# Content and Terminology

## Preferred language

| Use | Avoid in new copy | Note |
|---|---|---|
| learner | student, user | Database roles may remain `student` |
| mentor or facilitator | faculty as a catch-all | Legacy role `faculty` remains supported |
| programme | program | Code identifiers stay unchanged |
| counselling | counseling | Existing skill/category identifiers stay unchanged |
| organisation | organization | API/schema identifiers stay unchanged |
| application | registration form | “Registration” is reserved for settings or enrolment state |
| learning journal | diary | Clarifies academic reflection |
| catalogue | catalog | Route `/catalog` remains for compatibility |

## Voice

Write in direct British/Nigerian English. Be warm without being sentimental, and credible without sounding institutional. Name the next action. Explain why sensitive information is requested. Avoid manufactured urgency, guarantees, therapeutic promises or unverified professional claims.

## Dynamic content

Fees, dates, faculty profiles and accreditation claims must come from an approved source of truth. Until then, the public UI points applicants to the secure application process and the central configuration retains `client-confirmation-required` status.
